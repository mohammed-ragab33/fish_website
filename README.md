# موجة: متجر مأكولات بحرية (تصميم الصفحة الرئيسية)

صفحة رئيسية ثابتة (HTML وCSS وJavaScript) لمتجر مأكولات بحرية، بستايل فاخر غامق وحركات انيميشن.

## الملفات
- `index.html`: الصفحة
- `styles.css`: الستايل والحركات
- `main.js`: عداد الأسعار، وظهور الأطباق مع السكرول، وحركة إضافة المنتج للسلة
- `images/`: صور المنتجات

## التشغيل
افتح `index.html` في المتصفح، أو فعّل GitHub Pages من إعدادات الريبو (Settings ← Pages ← Branch: main).

## قبل النشر
- الأسعار في قسم "الأكثر طلباً" أمثلة للعرض. الأماكن المكتوب فيها [السعر] و[عدد] و[رقم التليفون] لازم تتملي ببيانات العميل.
- الصور من Unsplash وPexels تحت رخصهم المجانية. الأفضل استبدالها بصور منتجات العميل.
