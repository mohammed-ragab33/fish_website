# موجة: متجر مأكولات بحرية

موقع متجر بستايل فاخر غامق، فيه:
- **الصفحة الرئيسية** (`index.html`)
- **صفحة المنتجات** (`products.html`): فلتر بالأقسام، وبحث، وترتيب، واختيار الوزن
- **السلة وإتمام الطلب** (`cart.html`): الطلب بيتحفظ في قاعدة البيانات
- **لوحة التحكم** (`admin/`): صاحب المحل بيستلم الطلبات ويتابعها

## الملفات
| الملف | الوظيفة |
|---|---|
| `data/catalog.json` | المنتجات والأسعار والأقسام ومصاريف التوصيل. **غيّر الأسعار هنا بس** |
| `api/order.php` | بيستقبل الطلب، وبيحسب السعر من الكتالوج (مش من المتصفح)، وبيحفظه |
| `api/admin.php` | API لوحة التحكم: الدخول، والطلبات، وتغيير الحالة |
| `api/config.sample.php` | نموذج الإعدادات. انسخه باسم `config.php` |
| `admin/` | واجهة لوحة التحكم |

## الرفع على Hostinger
GitHub Pages بيعرض الصفحات بس. استقبال الطلبات ولوحة التحكم محتاجين PHP، فلازم Hostinger.

1. من لوحة Hostinger: **Databases ← MySQL Databases** اعمل قاعدة بيانات ومستخدم، واحفظ الاسم والباسوورد.
2. ارفع ملفات الريبو كلها في `public_html` (من File Manager، أو اربط الريبو من **Advanced ← Git**).
3. في فولدر `api` انسخ `config.sample.php` باسم `config.php`، وحط فيه بيانات قاعدة البيانات.
4. اعمل باسوورد لوحة التحكم: افتح **Advanced ← SSH** واكتب:
   `php -r "echo password_hash('الباسوورد بتاعك', PASSWORD_DEFAULT);"`
   وحط الناتج في `admin_hash` في `config.php`.
5. افتح `الدومين/admin` وسجّل دخول. الجداول بتتعمل لوحدها أول مرة.
6. (اختياري) حط إيميلك في `notify_email` عشان يوصلك تنبيه بكل طلب جديد.

## حالات الطلب
جديد ← اتأكد ← بيتجهز ← في الطريق ← اتسلم، أو اتلغى.
لوحة التحكم بتتحدث كل 20 ثانية، ولما يوصل طلب جديد بتعمل صوت وبيظهر تنبيه.

## قبل الافتتاح
- الأسعار ومصاريف التوصيل في `data/catalog.json` أمثلة. غيّرها بأرقام العميل.
- [رقم التليفون] و[مواعيد العمل] في الفوتر.
- الصور من Unsplash وPexels تحت رخصهم المجانية. الأفضل تتبدل بصور منتجات العميل.
